# Contributing

Suggestions from instructors and students are welcome.

- **Report a problem:** open an issue with the steps to reproduce it. Attach the project as JSON (Export → Project as JSON) if the problem depends on the data.
- **Propose an example project:** open an issue or a pull request adding a JSON file to `examples/`. Please include English and Arabic activity names (`name` and `name_ar`) and state the expected completion time and critical path.
- **Code changes:** the whole application is `index.html` (HTML, CSS and JavaScript, no build step). Keep it a single self-contained file with no new external libraries.

Please verify any CPM change against at least the built-in examples. Their expected results are listed in `docs/exercises-answers.md`.
